PROJECT OVERVIEW
================
Warp Weft & Co is a modern B2B denim sourcing agency website that connects fashion
brands with verified denim manufacturers worldwide. The platform showcases 
manufacturer capabilities, allows inquiry submissions, and provides company 
information with a focus on sustainability.

TECH STACK
==========
- Framework: Next.js 16 (App Router)
- Language: TypeScript 5.9.3
- UI Library: React 19.2.1
- Styling: Tailwind CSS 4.1.11 + Custom Theme
- Animations: Framer Motion 12.23.24
- Icons: Lucide React 0.553.0
- Database: Supabase (PostgreSQL)
- Forms: React Hook Form + Zod
- PDF Generation: PptxGenJS 4.0.1
- Deployment: Vercel
- Package Manager: npm

CORE FEATURES
=============

1. HOME PAGE
   - Full-screen hero with background image
   - Featured collections (3 items from Supabase or static)
   - About snippet
   - Process section
   - Call-to-action

2. COLLECTIONS BROWSER
   - Grid display of manufacturer profiles
   - Category filtering (All, Jeans, Jackets, Skirts)
   - Loading states with skeleton
   - Fallback to static data if Supabase unavailable
   - Click to view details

3. COLLECTION DETAIL PAGE
   - Dynamic routing: /collections/[id]
   - Image gallery with thumbnail navigation
   - Manufacturer capabilities checklist
   - "Request Introduction" and "Request Capability Statement" buttons
   - Pre-filled contact form

4. CONTACT FORM
   - Full name, email, subject, message fields
   - Subject can be pre-filled via URL params
   - Form validation
   - Saves to Supabase contacts table
   - Success animation and message
   - Toast notifications

5. ABOUT PAGE
   - Company story and history
   - Core values section
   - Responsive layout with images

6. SUSTAINABILITY PAGE
   - Eco-initiatives showcase
   - Certification badges
   - Four key areas: GOTS, Water, Circular Economy, Renewable Energy

7. PPT GENERATOR
   - Generates company presentation
   - 5 slides: Title, Heritage, Sustainability, Collections, Contact
   - Uses PptxGenJS library
   - Downloads automatically

DATA ARCHITECTURE
=================

SUPABASE TABLES
---------------

1. collections
   - id (UUID, primary key)
   - created_at (timestamp)
   - title (text)
   - category (text)
   - description (text)
   - long_description (text)
   - features (text[])
   - image (text)
   - images (text[])
   - is_featured (boolean)

2. contacts
   - id (UUID, primary key)
   - created_at (timestamp)
   - first_name (text)
   - last_name (text)
   - email (text)
   - subject (text)
   - message (text)

ROW LEVEL SECURITY (RLS)
------------------------
- collections: Public read access enabled
- contacts: Public insert only, no read access

FALLBACK STRATEGY
-----------------
All data fetching includes fallback to static data in lib/data.ts if:
- Supabase is not configured (null client)
- Network errors occur
- Database errors occur
- Invalid data format

ENVIRONMENT VARIABLES
=====================

REQUIRED (Production):
------------------------
NEXT_PUBLIC_SUPABASE_URL
  - Supabase project URL
  - Example: https://abcde.supabase.co
  - Public (prefixed with NEXT_PUBLIC_)

NEXT_PUBLIC_SUPABASE_ANON_KEY
  - Supabase anonymous key
  - From Settings → API
  - Public (prefixed with NEXT_PUBLIC_)

APP_URL
  - Application URL
  - Example: https://warpweft-and-co.vercel.app
  - Secret (no NEXT_PUBLIC_ prefix)

NODE_ENV
  - Environment: production
  - Secret

OPTIONAL:
---------
GEMINI_API_KEY
  - For AI features (not currently used)
  - Secret

NEXT_PUBLIC_ENABLE_PPT_DOWNLOAD
  - Toggle PPT download feature
  - Default: true
  - Public

NEXT_PUBLIC_ENABLE_ANALYTICS
  - Toggle analytics
  - Default: false
  - Public

TROUBLESHOOTING
===============

Issue: Collections not loading
Solution: Check Supabase connection, RLS policies, and environment variables

Issue: Build fails
Solution: Run `npm run build` locally first to catch TypeScript errors

Issue: Images not loading
Solution: Verify remotePatterns in next.config.ts includes the domain

Issue: PPT download not working
Solution: Check browser console, ensure pptxgenjs CDN loaded

Issue: Social icons not showing
Solution: Verify lucide-react icons are imported correctly
